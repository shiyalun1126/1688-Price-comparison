使用说明

四步走完一次完整的以款找源：建目标款 → 导入候选 → 匹配 → 比价询价。

01快速上手

  1. 创建目标款：工作台「＋ 新建目标款」，填名称并上传图片（视觉匹配必选）。
  2. 导入候选：切到「导入书签」页拿书签，去 1688 搜索页或详情页点一下。
  3. 执行匹配：回到工作台点「执行视觉匹配」，候选被分为完全同款 / 等效替代 / 已排除。
  4. 比价询价：「生成比价结论」看价格与成交条件；询价工作台逐家出话术、回贴报价。

02演示视频

方式一智能体自动分析
一句话下达目标 → ReAct 智能体自主调用工具（查看目标款 → 视觉匹配 → 比价），推理轨迹实时可见 → 输出比价结论与采购建议。
方式二书签手动导入
在导入页取书签 → 打开 1688 搜索结果页点一下书签 → 候选商品批量入库 → 执行视觉匹配分出同款/替代 → 生成比价结论。
进阶询价闭环
复制话术去旺旺问价 → 回贴卖家回复原话 → 自动解析出价格 / MOQ / 含税 / 现货 / 发货时效 / 阶梯价 → 重算比价结论，报价行自动排前。

03面试场景应对

面试官给出任何商品时，全程动态响应，无需提前准备：

  1. 打开该商品的 1688 详情页。
  2. 在「导入书签」页勾选「将此页商品设为新目标款」。
  3. 点书签 → 自动创建目标款并导入该商品。
  4. 再搜同类关键词，点书签批量导入候选。
  5. 回工作台点「执行视觉匹配」→ 出分层结果，继续比价与询价。
