使用说明

四步走完一次完整的以款找源：建目标款 → 抓候选 → 视觉匹配 → 自动询价。

01快速上手

  1. 建目标款：工作台「＋ 新建目标款」，填名称并上传图片（视觉匹配必须要有图）。
  2. 找货源：在 02 区填关键词，点「从 1688 抓候选」。智能体用你已登录的浏览器搜 1688，把商品连同真实店铺名、标价、主图一起入库，一次 20 件，不重复计入。
  3. 执行视觉匹配：候选被分成完全同款 / 等效替代 / 已排除。只有前两类会进入询价——连是不是这款都没确认就去问价，卖家报回来的数字跟目标款没关系，还像在乱发。
  4. 自动询价：询价工作台点「⚡ 自动询价」，智能体逐家开旺旺：发询价 → 只补问没答的项 → 拿市场最低价回头议价 → 收敛。
    卖家回话是后台自己取的，页面每 5 秒跟上一次，进度、缺口、轮次会自己变——不用刷新；切到别的标签页也会继续跟，标题上会显示未读。
  5. 表怎么看：询价表按状态分成「在谈 / 已报价 / 待询价 / 已排除」几组，默认只展开在谈的，其余折成一行，抓几十个候选也不会铺成两屏。点组标题展开或收起；02 区「候选池」点一档，下表就只剩那一档。

02三分钟看完一次谈判

询价工作台右上角两个按钮，走的是同一条决策逻辑，区别只在对面是谁：

  1. ▷ 演示一遍：剧本卖家用三分钟跑完「询价 → 补问缺口 → 议价 → 收工」，不碰真实账号、不用等卖家在线。想看完整过程就看这个。
  2. ⚡ 自动询价：真实发到你已登录的 1688。发送那一刻会截图存证，所以即使卖家几小时后才回，也能证明消息确实是它发的、不是人贴的。

点会话里的「对话」看完整往返。中间那些灰底带「决策」的行是它每一步的判断依据，不是事后编的说明——包括「还缺：是否含税、运费怎么算」这种缺口清单。

03它按什么规则谈

  1. 只问缺的：卖家答过的项不再重复问；同一句不会连发两遍。
  2. 卖家说「我去问一下」就等，不催不刷屏；对方报完价才回到议价。
  3. 要微信 / 电话 / 站外聊 → 立刻停手转人工。站外引流有风险，这条是硬规则，不是能力不够。
  4. 撞到验证码 → 整体暂停等人工，不重试硬闯。
  5. 配额：单次批量上限 8 家、每日 25 家、一家店一个款只聊一次，发送之间还有随机静默。

演示实例（给别人看的那份）会拒掉「⚡ 自动询价」，只让跑剧本——避免有人拿着你的号给真卖家发消息。要导入单个指定商品而不想撞详情页的滑块，用下面的书签方式。

04现场被给一个商品时

对方随手丢一个款过来，全程动态响应，不需要提前准备数据：

  1. 切到「书签导入」，勾上「将此页商品设为新目标款」，在 1688 详情页点一下书签 → 目标款和这一件候选同时建好。
  2. 回工作台，在 02 区填同类关键词，点「从 1688 抓候选」→ 20 件同类批量入库。
  3. 点「执行视觉匹配」，分出完全同款 / 等效替代 / 已排除。
  4. 点「⚡ 自动询价」，它自己去谈；谈的过程中点「对话」能实时看。
  5. 讲的时候盯住会话里的「决策」行——那是它自己判断出来的，不是照着剧本念。

开场前检查：抓取浏览器是否已启动并保持登录（没登录会让「找货源」和「自动询价」都失败）；挑一家缓存过旺旺号的店开场，能绕开详情页的滑块。
