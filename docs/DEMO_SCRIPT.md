# 演示剧本（3 分钟讲述路径）

> 适用场景：面试现场 / 屏幕共享演示。按此路径走，全程 3 分钟左右；
> 每步都标注了「讲什么」和「点什么」，照做即可，不需要现场发挥。

## 演示前检查（开场前 2 分钟）

1. 双击项目根目录 `start.bat`（或确认 8000 端口服务已在跑）
2. 浏览器打开 `http://127.0.0.1:8000/`
3. ⚠️ **全程不要点「强制刷新」类按钮**——比价结论走指纹缓存，秒出且结果稳定
4. 断网演练过 fallback：如果 LLM 掉线，话术/报价解析自动降级规则版（见文末预案）

## 讲述路径

### 第 1 步 · 开场定位（30 秒）

> "这是一个『以款找货源 + 比价』的智能体。场景是：我想要一批 POLO 衫，
> 把目标款录进来，系统在 1688 全网找同款、AI 判断谁是真的同款、
> 逐家询价、最后告诉我该买哪家、怎么砍价。"

**操作**：指着顶栏当前目标款「POLO衫」卡片（图片 + 参考价）。

### 第 2 步 · 数据怎么来的（30 秒）

> "候选商品有三种进来的方式：书签脚本在 1688 商品页一键导入；
> 或者让智能体自己接管浏览器去搜索、抓结果、下载主图入库；
> 也可以手动补录。现在这个款下有 14 家候选。"

**操作**：点侧栏「导入书签」展示书签页 3 步引导（10 秒即回）。

### 第 3 步 · 视觉匹配分层（30 秒）

> "拿到候选后，多模态大模型逐张比对目标款图和商品图，分三层：
> 完全同款才能进硬比价；等效替代只能参考；明确矛盾的被排除。
> 提示词是品类自适应的——服装看领型面料，数码看接口型号。
> 匹配是增量的，已判定过的不重复烧 token。"

**操作**：切到「保温杯」目标款——03 区会**自动回显**已算好的比价结论
（84 家候选，同款最低 17.5 元玮枫，橙色高亮行）。

### 第 4 步 · 比价结论（40 秒）

> "比价不只是比价格：可比性看八个维度——价格、MOQ、含税、运费、
> 现货、发货时效、阶梯价、匹配层级。标价和询价报价归一合并，
> 卖家真实报价优先。橙色高亮就是当前最低的可硬比价同款，
> 下面直接给出采购建议和议价话术。"

**操作**：滚动浏览结论表 + 指一下「建议」和「议价话术」块。

### 第 5 步 · 询价工作台（40 秒）

> "询价是半自动的：智能体生成带核验问题的话术，人拿去旺旺发送，
> 卖家回复原文贴回来，系统自动解析成结构化报价——价格、MOQ、
> 含税、现货、时效。报价落库后还会自动补跑这一家的视觉核验。
> 这个表按核验分层和价格排序，筛选 chip 一键看『已报价』的 7 家。"

**操作**：点「已报价」chip（剩 7 行）→ 点开任意「点开查看话术」展开话术。

### 第 6 步 · 智能体能力收尾（30 秒）

> "右侧控制台是一个 ReAct 智能体：DeepSeek function calling 驱动，
> 12 个业务工具自主规划——看数据、找候选、自动导入、匹配、比价、
> 出话术、制定长任务计划。轨迹和 token 用量全程可见，
> 对话记忆按目标款保留，长任务计划跨会话续跑。
> 底层数据全走指纹缓存，输入不变秒出结论、零 LLM 调用。"

**操作**：控制台展开最近一次对话，展示轨迹步骤 + token 统计。

### 收尾一句话

> "数据层 SQLite 每线程连接 + WAL，测试 65 个用例，
> 一键启动脚本拉起服务和抓取浏览器，代码在 GitHub 开源。"

## LLM 掉线 / 现场事故预案

| 症状 | 处理 |
|------|------|
| LLM 调用失败/超时 | 话术生成、报价解析、议价建议**自动降级规则版**，演示话术："这里演示的是离线降级路径，生产上换任何 OpenAI 兼容模型即可" |
| 比价结论突然重算（点了强制刷新） | 等它算完（约 10-20 秒），顺势讲指纹缓存机制："这就是为什么正常路径秒出" |
| 服务没起 | 双击 `start.bat`，日志在 `data/uvicorn.log` |
| 视觉判定与预期不同 | 直接讲："视觉模型有固有噪声，所以已判定结果默认复用缓存，不重算" |
| 浏览器抓取（auto_import）失败 | 不在现场演示它，只展示导入结果和轨迹回放；失败也是设计内降级（提示用书签） |
